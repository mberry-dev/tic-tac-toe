# Tic-Tac-Toe

A browser-based Tic-Tac-Toe game with full game logic and win detection.

## About
Classic two-player Tic-Tac-Toe playable in the browser. Includes win detection, draw detection, and a restart option.

## Features
- Two-player mode
- Win and draw detection
- Restart button

## Built With
- HTML, CSS, JavaScript

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
